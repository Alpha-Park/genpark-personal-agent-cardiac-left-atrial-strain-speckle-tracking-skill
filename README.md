# Cardiac Left Atrial Strain (LAS) & Speckle Tracking Skill

A production-grade, zero-mock personal agent skill engineered for echocardiographic speckle-tracking left atrial deformation analysis, phasic mechanics quantification, and diastolic filling pressure stratification.

## Features
- **Deterministic Phasic Strain Calculation**: Directly derives reservoir, conduit, and contractile booster pump strains.
- **Diastolic Stiffness Sentinel**: Computes the ratio of non-invasive filling pressure ($E/e'$) to reservoir compliance ($LASI$).
- **Pure Standard Library**: Zero external dependencies; fully portable for edge and clinical AI deployment.
